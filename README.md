# OceanSurvey
Oceanographic Survey Database and KML Mapping Tool

OceanSurvey is a Windows desktop application for managing oceanographic survey information, organizing survey files, and visualizing survey locations on a map.

## Key Features

- **Survey Management:** Manage oceanographic survey information.
- **Map Visualization:** Display survey locations on a map.
- **KML Export:** Export survey locations for use in compatible mapping applications.
- **File Management:** Organize survey documents and related files.
- **Flexible Storage:** Select the directory used to store survey data.
- **Bilingual Interface:** Switch between Vietnamese and English.

## User Guide

### 1. Launch the Application

1. Download the `.exe` file.
2. Save it to a suitable folder on your computer.
3. Double-click the executable to launch OceanSurvey.
4. If Windows displays a security warning, verify that the file comes from the official release before proceeding.

### 2. Select the Data Directory

On the first launch, follow the application prompts to select the directory used to store survey data.

Choose a location where you have permission to create and modify files.

### 3. Manage Survey Information

Use the application interface to create, view, edit, and manage survey records.

Enter the relevant survey information and geographic coordinates as required by the application.

### 4. View Survey Locations on the Map

Open the map interface to visualize survey locations.

Use the available map tools to explore the geographic distribution of survey points.

### 5. Export KML Files

Use the KML export function to export survey locations.

The exported KML files can be opened in compatible mapping applications, such as Google Earth.

### 6. Change the Interface Language

Use the language selection option to switch between Vietnamese and English.

## Important Notes

- Keep a backup of your survey database and important files.
- Do not delete or move application data files while the application is running.
- Store survey data in a directory with appropriate read and write permissions.
- Available features may vary between versions.
